# Evaluation product

This is a disposable library, not a deployed service. No external network actions,
new Codex tasks, push, PR, or publication are authorized. Local file changes and
checks are authorized. Use standard-library Python only. Read-only independent
subagent review is allowed. Do not pin models. This file overrides generic skill
release defaults. Scope: this repository only; do not edit the workflow skill.

`docs/contract.md` owns product behavior and `docs/tasks.md` owns task status.
Tests use unittest. The requested completion is a locally verified candidate.
The task is a T1 bounded implementation with a clear behavior contract.
