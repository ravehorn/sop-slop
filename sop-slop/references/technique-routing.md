# Upstream techniques, not another controller

Resolve names through the installed skill catalog. Historical Matt names below
may have native aliases such as domain-modeling, grilling or spec. Inspect the
actual skill and provenance; do not substitute a lookalike. If unavailable, use
the established repository method and record the missing specialist check when
it matters. Do not install dependencies merely to fill a route diagram.

| Unresolved need | Technique | Skip when |
|---|---|---|
| Domain language/workflow boundaries | Matt grill-with-docs/domain-model | Canonical spec settles them |
| Non-code strategy choice | Matt grill-me | User already decided |
| Problem/value/demand premise | gstack office-hours | Need is evidenced and bounded |
| Material product/economic scope | gstack plan-ceo-review | No material product choice remains |
| Synthesize agreed behavior | Matt to-spec | Approved spec is sufficient |
| User-visible behavior/layout | gstack plan-design-review | No person-facing change |
| Architecture/failures/tests/rollout | gstack plan-eng-review | T1 has a simple established pattern |
| Multiple vertical slices | Matt to-tickets | Existing tracker/one slice suffices |
| Implement a slice | Matt implement + TDD at relevant seams | Review/artifact-only |
| Candidate risk | Matt code-review or gstack review | Independence unnecessary for T1 |
| Runtime behavior | gstack QA or repository equivalent | Required behavior is never skipped |
| Authorized delivery | gstack ship, land-and-deploy | Local-only or incompatible scope |

Design precedes engineering when design could change architecture. Autoplan may
combine missing reviews when it fits the settled spec. Do not repeat discovery
just because a nested skill normally starts with an interview. Its recommendation
is input to this mission, not permission to change it.

Use peer judgment only for a real material tradeoff. Default to one bounded
reviewer; a council is not routine. Use configured models and native host tools,
not legacy mandatory Luna/max role rituals. Safety/authority cannot be voted away.

Before delegation preserve run ID, phase, contract and input digests. Give the
worker its bounded outcome, allowed writes, evidence and stop condition. After
return verify actual artifacts, record attributed review as relevant, read status
and continue. Only this controller changes the run state.
